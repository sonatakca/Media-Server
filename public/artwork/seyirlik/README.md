# SEYİRLİK generated brand artworks

19 standalone PNG explorations, generated with the built-in image_gen tool on 2026-09-12. No website UI, favicon, manifest or existing brand asset consumes these files.

The supplied SEYİRLİK concept provides the shapes and compositions; the Klei references provide hand-cut typographic inspiration only. The reference palette is superseded by the website colors in `src/lib/accentTheme.ts` and `src/index.css`.

Accent targets: Warm Red `#bd3f28`, Amber `#fa9b1d`, Gold `#d3ca22`, Olive `#bacb7d`, Green `#67a478`, Teal `#337b6c`. Neutral targets: `#f8fafc` and `#050607`. These are raster explorations: generated color and texture vary slightly from the requested hex targets, and independently generated letterforms vary. Files have opaque backgrounds; they are not vector or transparent production masters.

The [manifest](manifest.json) records every final prompt, the palette sources, and asset paths. Source reference images are not redistributed.
